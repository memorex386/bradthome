# Spec 040: states

The mocks are this slice's own build, captured on 2026-11-16 in Chromium at 1× density from a local preview of the production build by [capture.mjs](capture.mjs), with reduced motion, at 375 × 812 and 1440 × 900. The site and the résumé PDFs were built in the pinned Playwright container, as CI builds them. The section shots hide the sticky header and the floating "Ask about Brad", which would cover them. Where a state compares an option with the build, the option's words were set in the built page for the shot, and the state says so. Once the slice lands, `tests/snapshots/040/` holds each state's baseline from the pinned container, and the pages on `next` are the record.
