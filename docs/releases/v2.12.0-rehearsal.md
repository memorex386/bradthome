# Rehearsal: release v2.12, roll back to v2.11

This is the rehearsal for v2.12.0, which releases slice 5.14, VINDecoded's live card ([spec 041](../../specs/041-vindecoded-pulse/spec.md)), and slice 5.15, what Brad is looking for ([spec 042](../../specs/042-looking-for/spec.md)). It ran on 2026-11-18 (UTC) from main's `103a8a0`, before v2.12 reached the live channel. It used preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, under Brad's own login, as the [v2.11.0 rehearsal](v2.11.0-rehearsal.md) did.

## Setup

- The candidate was `103a8a0`'s build, made in the pinned Playwright container as `pnpm test:visual` makes it. The build printed the résumé PDFs and passed `pnpm csp --check`. Main's `ci`, `next` and CodeQL had passed on `103a8a0`, with no open code-scanning alert.
- The candidate was deployed with the repo's `firebase.json` to a new channel, `v212-cand`, as version `2f691815ae046656`. The check waited 45 seconds before reading it.
- Releases went to `rehearsal-v212`, a channel created for the rehearsal. Both channels expire a day later.
- v2.11.0, which bradthome.com served, is version `52a2a8a761dd1950` (`pnpm release:status`).
