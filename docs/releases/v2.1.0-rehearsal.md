# Rehearsal: release v2.1, roll back to v2.0.1

The rehearsal for spec 023 (slice 4.4, S6.5, FR-016), run on 2026-11-09 after the slice reached main at `b833a71`, before v2.1 reached the live channel. It ran on preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, as Brad's own login, as the [v2.0.0 rehearsal](v2.0.0-rehearsal.md) did.

## Setup

- The candidate was `b833a71`'s build, made in the pinned Playwright container by `pnpm test:visual`, with the résumé PDFs printed and `pnpm csp --check` passing. It was deployed with the repo's `firebase.json` to channel `v21-rc` as version `c9790e881313be8a`.
- Releases went to channel `rehearsal-v21`, created for the rehearsal, expiring a day later.
- v2.0.1, which bradthome.com serves, is version `df9752f09d14ca9e` (`pnpm release:status`).

## What the rehearsal found

The first pre-release check against `v21-rc` failed every URL on its Content-Security-Policy. The check allowed `connect-src` to add only Umami's host ([D159](../decisions/0159-spec-003-allows-umamis-api-host.md)), and v2.1 adds the chat API's address ([D198](../decisions/0198-v2-1-lets-bradthome-com-call-the-chat-api.md)). The release workflow's stage job runs the same check, so v2.1 would have stopped there. `scripts/release/check.ts` now allows the chat API's address in `connect-src` too, and spec 019's test of that list changed with it. Any other added host still fails the check.

## The pre-release check

Against bradthome.com, with the words allowed to change, as the release runs with `words-may-change=true`:

```text
$ pnpm release:check --candidate https://bradthome--v21-rc-76br1pdp.web.app --words-may-change
– check  Hosting sets its own HSTS on bradthome--v21-rc-76br1pdp.web.app, so the check reads firebase.json at b833a71's: max-age=63072000; includeSubDomains
– check  words differ on /: live has “Read the résumé brad@bradthome.com Hopper · Fintech AI Capital One Travel 10+”, candidate has “Read the résumé brad@bradthome.com Ask about Brad Hopper · Fintech AI Capital” (this run allows it)
– check  words differ on /vindecoded-agents: live has “no CI; with one engineer, a hosted run on every pull request”, candidate has “no CI; with one person reviewing, a hosted run on every pull” (this run allows it)
✓ check  https://bradthome--v21-rc-76br1pdp.web.app serves every URL, redirect, security header and word that https://bradthome.com does (29 URLs, 2 pages' words)
```

The home gains the "Ask about Brad" button, and the essay's line changes as [D199](../decisions/0199-the-essay-says-one-person-reviewing-not-one-engineer.md) set out. Those are the only word changes.
