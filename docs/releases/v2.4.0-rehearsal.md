# Rehearsal: release v2.4, roll back to v2.3

The rehearsal for v2.4.0, which releases the landing study's direction A slices A5 and A6 together (specs 029 and 030). It ran on 2026-11-11 from main's `a2f10d1`, before v2.4 reached the live channel. It ran on preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, as Brad's own login, as the [v2.3.0 rehearsal](v2.3.0-rehearsal.md) did.

## Setup

- The candidate was `a2f10d1`'s build, made in the pinned Playwright container by `pnpm test:visual`, with the résumé PDFs printed and `pnpm csp --check` passing. It was deployed with the repo's `firebase.json` to channel `v24-rc` as version `d2d78e1f8252b34c`.
- Releases went to channel `rehearsal-v24`, created for the rehearsal, expiring a day later.
- v2.3.0, which bradthome.com served, is version `fdf4b3fe52e506d8` (`pnpm release:status`).

## The pre-release check

Against bradthome.com, with no words allowed to change, since A5 and A6 change none:

```text
$ pnpm release:check --candidate https://bradthome--v24-rc-gd6j5qms.web.app
– check  Hosting sets its own HSTS on bradthome--v24-rc-gd6j5qms.web.app, so the check reads firebase.json at a2f10d1's: max-age=63072000; includeSubDomains
✓ check  https://bradthome--v24-rc-gd6j5qms.web.app serves every URL, redirect, security header and word that https://bradthome.com does (31 URLs, 2 pages' words)
```

## The run

```text
started 2026-11-11T13:27:19Z
created channel `rehearsal-v24`, at https://bradthome--rehearsal-v24-1j3w1kfq.web.app
$ node scripts/release/release.ts --version d2d78e1f8252b34c --channel rehearsal-v24 --staged-channel v24-rc
✓ release  version d2d78e1f8252b34c is served on rehearsal-v24 at https://bradthome--rehearsal-v24-1j3w1kfq.web.app: 39 files, after 4 s
$ node scripts/release/rollback.ts --channel rehearsal-v24 --version fdf4b3fe52e506d8
✓ rollback  version fdf4b3fe52e506d8 is served on rehearsal-v24 at https://bradthome--rehearsal-v24-1j3w1kfq.web.app: 39 files, rollback served after 22 s
rollback command took 25 s end to end
finished 2026-11-11T13:27:53Z
```

Each ✓ line means every file of the version answered at its address with its hash as the ETag. Creating the channel also printed Firebase's notice that it couldn't add the channel's domain to Firebase Auth, which the site doesn't use.
