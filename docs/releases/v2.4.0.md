# v2.4.0: role pages morph, and "Ask me" opens the chat

bradthome.com moved from v2.3.0 to v2.4.0 on 2026-11-11 (UTC). The release puts the landing study's last two direction A slices on live, so all six are there:

- [spec 029](../../specs/029-landing-a5/spec.md): switching roles morphs the page with a cross-document View Transition. The switch's mark slides, the eyebrow and note crossfade, the lit word and rows relight, and Hopper's topics move to their new order ([D212](../decisions/0212-role-pages-morph.md)).
- [spec 030](../../specs/030-landing-a6/spec.md): each "Ask me" receipt, and each drawer's ask link, opens Ask about Brad with a question from its claim in the box, for the visitor to send. The floating button rises into place once the hero has settled ([D213](../decisions/0213-ask-me-opens-the-chat.md)).

Motion plays only when the visitor allows it. Brad approved the release in the career session ("Yes, release"), and again in the `production` environment. The rehearsal before it is in [v2.4.0-rehearsal.md](v2.4.0-rehearsal.md), and the runbook is [docs/release.md](../release.md).

## The release

- Tag: `v2.4.0`, annotated and unsigned like v2.3.0, on main's `a2f10d1`. GitHub release: [v2.4.0](https://github.com/memorex386/bradthome/releases/tag/v2.4.0).
- Main's `ci`, `next` and "Push on main" passed on `a2f10d1` before the tag.
- Run: [release 43029411028](https://github.com/memorex386/bradthome/actions/runs/43029411028), with no words allowed to change. The stage job put version `6c6f319e8b1fef91` on the `release` channel, and its pre-release check against v2.3.0 on bradthome.com printed:

  ```text
  ✓ check  https://bradthome--release-gn6n25b2.web.app serves every URL, redirect, security header and word that https://bradthome.com does (31 URLs, 2 pages' words)
  ```

- Brad approved the release job in the `production` environment. It printed:

  ```text
  ✓ release  version 6c6f319e8b1fef91 is served on live at https://bradthome.com: 39 files, after 4 s
  ```

- `pnpm release:status` then read `live (https://bradthome.com) serves version 6c6f319e8b1fef91, released 2026-11-11T13:52:53.342Z: v2.4.0 (a2f10d1)`. A rollback would put back v2.3.0's `fdf4b3fe52e506d8`.

The chat API, its prompt and its model didn't change, so v2.4 needed no `pnpm chat-api:deploy`. The new eval cases ran in CI before the slice landed, and the `evals/030-ask-me` branch was deleted after the release, as [D193](../decisions/0193-eval-runs-start-from-an-evals-branch.md) says.
