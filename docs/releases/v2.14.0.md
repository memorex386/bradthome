# v2.14.0: a warmer voice for the chat, with three questions to ask next

bradthome.com moved from v2.13.0 to v2.14.0 on 2026-11-19 (UTC). The release puts one slice on live:

- **Slice 5.18, the chat's voice ([spec 045](../../specs/045-chat-voice/spec.md), [D249](../decisions/0249-the-chat-speaks-in-a-referral-voice.md)–[D252](../decisions/0252-the-conversation-is-capped-at-12000-characters.md)):**
  - Ask about Brad answers like a friend referring Brad, with cited specifics, and never grades Brad.
  - Under the newest answer, "Ask next" offers three questions the model writes, which the API checks in code before they reach the browser, and fills from the starters when one fails.
  - Small talk has its own `chat` state, and the hand-offs follow the kind of reply: salary and availability still end with the email sentence and "Email Brad".
  - A conversation is capped at 12,000 characters, and the window drops its oldest turns to fit.

The voice reached the chat with the API's deploy earlier the same day. The window's pills reach visitors with this release. Brad typed "Deploy it" for the API, then "Release v2.14", which covered the rehearsal, the tag and the release run, approved the release job in the `production` environment from Brad's account, and typed "push" for this record. The runbook is [docs/release.md](../release.md). Code changed since v2.13.0, so this release took the usual path, not D248's short one.
