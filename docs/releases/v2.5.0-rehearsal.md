# Rehearsal: release v2.5, roll back to v2.4

The rehearsal for v2.5.0, which releases slice 5.7, "Ask about Brad" in reach on a phone (spec 031). It ran on 2026-11-11 from main's `fa66054`, before v2.5 reached the live channel. It ran on preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, as Brad's own login, as the [v2.4.0 rehearsal](v2.4.0-rehearsal.md) did.

## Setup

- The candidate was `fa66054`'s build, made in the pinned Playwright container by `pnpm test:visual`, with the résumé PDFs printed and `pnpm csp --check` passing. It was deployed with the repo's `firebase.json` to channel `v25-rc` as version `bf1a35926710cd72`.
- Releases went to channel `rehearsal-v25`, created for the rehearsal, expiring a day later.
- v2.4.0, which bradthome.com served, is version `6c6f319e8b1fef91` (`pnpm release:status`).

## The pre-release check

Against bradthome.com, with no words allowed to change, it stopped:

```text
$ pnpm release:check --candidate https://bradthome--v25-rc-1gax5g20.web.app
– check  Hosting sets its own HSTS on bradthome--v25-rc-1gax5g20.web.app, so the check reads firebase.json at fa66054's: max-age=63072000; includeSubDomains
✖ check  words differ on /: live has “AI Ask about Brad End to end Where I work Android Kotlin,”, candidate has “AI Ask about Brad Ask about Brad End to end Where I”
```

The home's words now hold "Ask about Brad" twice, since the phone's corner button repeats the hero's label. Brad chose on a card in the session to allow the home's words to change, as v2.0 did. Then:

```text
$ pnpm release:check --candidate https://bradthome--v25-rc-1gax5g20.web.app --home-words-may-change
– check  words differ on /: live has “AI Ask about Brad End to end Where I work Android Kotlin,”, candidate has “AI Ask about Brad Ask about Brad End to end Where I” (this run allows it)
✓ check  https://bradthome--v25-rc-1gax5g20.web.app serves every URL, redirect, security header and word that https://bradthome.com does (31 URLs, 2 pages' words)
```

## The run

```text
started 2026-11-11T16:21:26Z
created channel `rehearsal-v25`, at https://bradthome--rehearsal-v25-vt408ra9.web.app
$ node scripts/release/release.ts --version bf1a35926710cd72 --channel rehearsal-v25 --staged-channel v25-rc
✓ release  version bf1a35926710cd72 is served on rehearsal-v25 at https://bradthome--rehearsal-v25-vt408ra9.web.app: 39 files, after 4 s
$ node scripts/release/rollback.ts --channel rehearsal-v25 --version 6c6f319e8b1fef91
✓ rollback  version 6c6f319e8b1fef91 is served on rehearsal-v25 at https://bradthome--rehearsal-v25-vt408ra9.web.app: 39 files, rollback served after 4 s
rollback command took 6 s end to end
finished 2026-11-11T16:21:42Z
```

Each ✓ line means every file of the version answered at its address with its hash as the ETag. Creating the channels also printed Firebase's notice that it couldn't add the channel's domain to Firebase Auth, which the site doesn't use.
