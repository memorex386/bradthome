# Rehearsal: release v2.15, roll back to v2.14

This is the rehearsal for v2.15.0, which releases slice 5.20, the offer agent's looping replay and its four claims ([spec 047](../../specs/047-offer-agent-replay/spec.md)). It ran on 2026-11-20 (UTC) from main's `7d88beb`, before v2.15 reached the live channel. It used preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, under Brad's own login, as the [v2.14.0 rehearsal](v2.14.0-rehearsal.md) did. Code changed since v2.14.0, so this release takes the usual path, not D248's short one.

## Setup

- The candidate was `7d88beb`'s build, made in the pinned Playwright container as `pnpm test:visual` makes it. The build printed the résumé PDFs and passed `pnpm csp --check`, and spec 047's 22 browser tests passed against it. Main's `ci`, `next` and "Push on main" had passed on `7d88beb`, with no open code-scanning alert.
- The candidate was deployed with the repo's `firebase.json` to a new channel, `v215-cand`, as version `b110f0cc7618b8f5`.
- Releases went to `rehearsal-v215`, a channel created for the rehearsal. Both channels expire a day later.
- v2.14.0, which bradthome.com served, is version `90a942671cfe2719` (`pnpm release:status`).
