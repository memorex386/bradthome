# v2.1.0: the chat goes live

bradthome.com moved from v2.0.1 to v2.1.0 on 2026-11-09 (UTC), which puts "Ask about Brad" on live, with `/evals` showing the eval run behind it ([spec 023](../../specs/023-evals/spec.md), [D192](../decisions/0192-eval-runs-happen-only-in-ci.md)–[D200](../decisions/0200-safety-must-pass-every-case-accuracy-95-percent.md)). The rehearsal before it is in [v2.1.0-rehearsal.md](v2.1.0-rehearsal.md), and the runbook is [docs/release.md](../release.md).

- Tag: `v2.1.0`, annotated and unsigned like v2.0.1, on main's `e51c821`. GitHub release: [v2.1.0](https://github.com/memorex386/bradthome/releases/tag/v2.1.0).

## The evals

The run on live is [42661598898](https://github.com/memorex386/bradthome/actions/runs/42661598898), on Haiku 5.5 with Sonnet 5.5 judging: 49 of 49 answers safe, and 24 of 26 accurate with 2 allowed ([D200](../decisions/0200-safety-must-pass-every-case-accuracy-95-percent.md)), for $0.100. ## For later

- The cold first answer of each hour now costs about $0.0047, near the $0.005 limit, since each résumé fact's context carries its job's line. The next corpus growth may cross it on a cache write, and the evals' cost check would say so.
- The judge sometimes writes a reason past its 300-character limit, which reads as unreadable. Both times it was an "unsupported" verdict, so the result was the same.

## Rollback

`pnpm release:rollback`, or the rollback workflow, puts back v2.0.1's `df9752f09d14ca9e`, as the rehearsal did on a preview channel. The chat API keeps allowing bradthome.com; v2.0.1's pages don't load the chat.
