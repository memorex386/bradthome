# Rehearsal: release v2.11, roll back to v2.10

This is the rehearsal for v2.11.0, which releases slice 5.13, the job history in date order ([spec 040](../../specs/040-job-order/spec.md)). It ran on 2026-11-17 from main's `f0d27d4`, before v2.11 reached the live channel. It used preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, under Brad's own login, as the [v2.10.0 rehearsal](v2.10.0-rehearsal.md) did.

## Setup

- The candidate was `f0d27d4`'s build, made in the pinned Playwright container as `pnpm test:visual` makes it. The build printed the résumé PDFs, each two pages, and drew the six share cards, and `pnpm csp --check` passed. Main's `ci`, `next` and CodeQL had passed on `f0d27d4`.
- The candidate was deployed with the repo's `firebase.json` to a new channel, `v211-cand`, as version `f89db3d1ec364189`. The check waited 45 seconds before reading it, as the v2.7 rehearsal did.
- Releases went to `rehearsal-v211`, a channel created for the rehearsal. Both channels expire a day later.
- v2.10.0, which bradthome.com served, is version `0c95b3186fa8ffff` (`pnpm release:status`).

## The pre-release check

The check ran against bradthome.com with the home's words allowed to change, as the release run sets `words-may-change=home`. The Experience section's heading and RealPage's card are words on the home. The essay's words don't change, and no other page's words are compared.

```text
$ pnpm release:check --candidate https://bradthome--v211-cand-2errbk1g.web.app --home-words-may-change
– check  Hosting sets its own HSTS on bradthome--v211-cand-2errbk1g.web.app, so the check reads firebase.json at f0d27d4's: max-age=63072000; includeSubDomains
– check  words differ on /: live has “Android for brands, a startup and a sports media platform Apr 2022”, candidate has “Android for brands, a startup, real-estate apps and a sports media platform” (this run allows it)
✓ check  https://bradthome--v211-cand-2errbk1g.web.app serves every URL, redirect, security header and word that https://bradthome.com does (44 URLs, 2 pages' words)
```
