# Rehearsal: release v2.14, roll back to v2.13

This is the rehearsal for v2.14.0, which releases slice 5.18, a warmer voice for Ask about Brad with three questions to ask next ([spec 045](../../specs/045-chat-voice/spec.md)). It ran on 2026-11-19 (UTC) from main's `279fb40`, before v2.14 reached the live channel. It used preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, under Brad's own login, as the [v2.13.0 rehearsal](v2.13.0-rehearsal.md) did. Code changed since v2.13.0, so this release takes the usual path, not D248's short one.

## Setup

- The candidate was `279fb40`'s build, made in the pinned Playwright container as `pnpm test:visual` makes it. The build printed the résumé PDFs and passed `pnpm csp --check`, and spec 045's 14 window tests passed against it. Main's `ci`, `next` and CodeQL had passed on `279fb40`, with no open code-scanning alert.
- The candidate was deployed with the repo's `firebase.json` to a new channel, `v214-cand`, as version `6b44efa8ac7f2245`.
- Releases went to `rehearsal-v214`, a channel created for the rehearsal. Both channels expire a day later.
- v2.13.0, which bradthome.com served, is version `2f29880338456249` (`pnpm release:status`).
