# Rehearsal: release v2.7, roll back to v2.6

This is the rehearsal for v2.7.0, which releases three changes:

- spec 034's Capital One receipts;
- slice 5.9, how bradthome.com is built (spec 033);
- spec 035's essay lines and judge's notes.

It ran on 2026-11-12 from main's `ea044a9`, before v2.7 reached the live channel. It used preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, under Brad's own login, as the [v2.6.0 rehearsal](v2.6.0-rehearsal.md) did.

## Setup

- The candidate was `ea044a9`'s build, made in the pinned Playwright container by `pnpm test:visual`. The build printed the résumé PDFs, and `pnpm csp --check` passed.
- The candidate was deployed with the repo's `firebase.json` to a new channel, `v27-cand`, as version `28c8f1511b9ec0ed`. The check waited 45 seconds before reading it, after the v2.6 rehearsal's first channel served a cached "Site Not Found".
- Releases went to `rehearsal-v27`, a channel created for the rehearsal that expires a day later.
- v2.6.0, which bradthome.com served, is version `55eb8420929a08ec` (`pnpm release:status`).

## The pre-release check

The check ran against bradthome.com with words allowed to change on the home and the essay, as the release run sets `words-may-change=home-and-essay`:

- On the home, spec 034 rewords Hopper's Capital One claim, and slice 5.9 adds bradthome.com's card.
- In the essay, spec 035 rewords two lines.
- No other page's words are compared.
