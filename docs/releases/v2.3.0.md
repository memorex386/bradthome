# v2.3.0: the landing study's direction A goes live

bradthome.com moved from v2.2.0 to v2.3.0 on 2026-11-11 (UTC), which puts the landing study's direction A, slices A1–A4, on live together:

- [spec 025](../../specs/025-landing-a1/spec.md): the role switch moves under the hero, with proof tiles.
- [spec 026](../../specs/026-landing-a2/spec.md): each card gathers its receipts in one drawer beside its tags.
- [spec 027](../../specs/027-landing-a3/spec.md): a sticky header that marks the section, and a footer that links the repo.
- [spec 028](../../specs/028-landing-a4/spec.md): sections reveal their evidence once, the figures carry a rule, and the copy button draws a check ([D211](../decisions/0211-sections-reveal-their-evidence-once.md)).

Motion plays only when the visitor allows it. Slices A5 and A6 (specs 029 and 030) landed on main after `19913df` and wait for the next release. The rehearsal before it is in [v2.3.0-rehearsal.md](v2.3.0-rehearsal.md), and the runbook is [docs/release.md](../release.md).

## The release

- Tag: `v2.3.0`, annotated and unsigned like v2.2.0, on main's `19913df`. GitHub release: [v2.3.0](https://github.com/memorex386/bradthome/releases/tag/v2.3.0).
- Main's `ci`, `next` and "Push on main" passed on `19913df` before the tag.
- Run: [release 42915968077](https://github.com/memorex386/bradthome/actions/runs/42915968077), with `words-may-change=home`, since A1 changed the home's words on purpose. The stage job put version `fdf4b3fe52e506d8` on the `release` channel, and its pre-release check against v2.2.0 on bradthome.com printed:

  ```text
  ✓ check  https://bradthome--release-gn6n25b2.web.app serves every URL, redirect, security header and word that https://bradthome.com does (31 URLs, 2 pages' words)
  ```

  Only the home's words differed, which the run allowed. The essay's words matched.

- Brad approved the release job in the `production` environment. It printed:

  ```text
  ✓ release  version fdf4b3fe52e506d8 is served on live at https://bradthome.com: 39 files, after 4 s
  ```

- `pnpm release:status` then read `live (https://bradthome.com) serves version fdf4b3fe52e506d8, released 2026-11-11T01:58:13.447Z: v2.3.0 (19913df)`. A rollback would put back v2.2.0's `3ef869c390b26244`.

The chat API didn't change, so v2.3 needed no `pnpm chat-api:deploy`.
