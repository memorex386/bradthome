# Rehearsal: release v2.10, roll back to v2.9

This is the rehearsal for v2.10.0, which releases slice 5.12, the pictures ([spec 039](../../specs/039-pictures/spec.md)). It ran on 2026-11-16 from main's `0771a9c`, before v2.10 reached the live channel. It used preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, under Brad's own login, as the [v2.7.0 rehearsal](v2.7.0-rehearsal.md) did.

## Setup

- The candidate was `0771a9c`'s build, made in the pinned Playwright container by `pnpm test:visual`. The build printed the résumé PDFs and drew the six share cards, `pnpm csp --check` passed, and spec 039's end-to-end tests passed.
- The candidate was deployed with the repo's `firebase.json` to a new channel, `v210-cand`, as version `ed3eeb32bf87541e`. The check waited 45 seconds before reading it, as the v2.7 rehearsal did.
- Releases went to `rehearsal-v210`, a channel created for the rehearsal. Both channels expire a day later.
- v2.9.0, which bradthome.com served, is version `7e055f3009c6d7ff` (`pnpm release:status`).

## The pre-release check

The check ran against bradthome.com with the home's words allowed to change, as the release run sets `words-may-change=home`. The Capital One diagram's labels are words on the home, after its claims. The essay's words don't change, and no other page's words are compared.

```text
$ pnpm release:check --candidate https://bradthome--v210-cand-8itv02hj.web.app --home-words-may-change
– check  Hosting sets its own HSTS on bradthome--v210-cand-8itv02hj.web.app, so the check reads firebase.json at 0771a9c's: max-age=63072000; includeSubDomains
– check  words differ on /: live has “to Capital One customers. Sources The offer card, in a 2024 travel-blog”, candidate has “to Capital One customers. Sole engineering owner RFC and ADR, stakeholder alignment” (this run allows it)
✓ check  https://bradthome--v210-cand-8itv02hj.web.app serves every URL, redirect, security header and word that https://bradthome.com does (31 URLs, 2 pages' words)
```

## The run

```text
started 2026-11-16T20:00:06Z
created channel `rehearsal-v210`, at https://bradthome--rehearsal-v210-1po3ihwz.web.app
```

Each ✓ line means every file of the version answered at its address, with its hash as the ETag. The candidate has 13 more files than v2.9.0: the six share cards, the four sizes of the photo, the home-screen icon and the two marks.
