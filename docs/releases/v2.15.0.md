# v2.15.0: the offer agent, replayed

bradthome.com moved from v2.14.0 to v2.15.0 on 2026-11-21 (UTC). The release puts one slice on live, and carries slice 5.19's records, whose prompt the chat API already ran:

- **Slice 5.20, the offer agent's replay ([spec 047](../../specs/047-offer-agent-replay/spec.md), [D254](../decisions/0254-the-offer-agent-as-a-looping-replay.md)–[D257](../decisions/0257-the-pdfs-print-no-new-hopper-claim.md)):**
  - The Hopper band's Fintech AI card shows four new claims in Brad's words: the AI sales agent Brad built most of for Hopper's flight booking, how it was grounded, how it shipped, and its A/B result.
  - After them, a looping replay plays the conversation on a phone beside an illustrative "Under the hood" trace, labeled as an illustration drawn from Brad's account with sample data. Pause comes first, and it plays only while in view. Under reduced motion it stands still. Its player and styles load only as it nears the screen.
  - `/offer-agent` shows both ways the conversation goes as plain HTML, the text alternative and the frame a visitor with no script reads.
  - The résumé PDFs and the Content-Security-Policy don't change.

Brad typed "Go ahead" to the release and the chat's redeploy in the career session. In this session Brad then chose v2.15.0 on a card, approved the release job in the `production` environment from Brad's account, and chose "Deploy it" for the chat API on its own card. The first deploy attempt failed before it reached Cloud Run, and Brad approved the retry on a new card. The runbook is [docs/release.md](../release.md). Code changed since v2.14.0, so this release took the usual path, not D248's short one.

## The chat API

On Brad's "Deploy it", `pnpm chat-api:deploy` ran from main's `7d88beb` after the release, so the chat answers from the corpus with the four claims. The first run stopped before it reached Cloud Run: a container test run had left Linux packages in the checkout, so `zod` wouldn't load. The service kept serving `chat-api-00018-7x2`. After a Windows reinstall and Brad's new go-ahead, the second run deployed revision `chat-api-00019-9dt`, which takes all traffic, on 0 to 2 instances, with `claude-haiku-5-5`, as `chat-api@`. The prompt and model didn't change. It printed D244's warning that no full eval run checked this prompt and model, since the evals are off. `/health` answers 200, and the "what it was" claim's sparkle question on bradthome.com got an answer in the four claims' words, citing Hopper's Fintech AI sources.
