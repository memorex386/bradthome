# v2.0.0: the relaunch

bradthome.com moved from v1.0.0 to v2.0.0, the phase 3 redesign, on 2026-11-06 ([spec 019](../../specs/019-relaunch/spec.md), [D58](../decisions/0058-v1-0-at-the-end-of-phase-2-the-relaunch-as-v2-0.md), [D162](../decisions/0162-the-new-home-moves-to-the-root-and-v2-redirects-there.md)–[D168](../decisions/0168-the-home-and-the-essay-are-indexable.md)). This is spec 019's S7.2–S7.4 and SC-001, SC-003 and SC-005 evidence. The rehearsal before it is in [v2.0.0-rehearsal.md](v2.0.0-rehearsal.md), and the runbook is [docs/release.md](../release.md).

- Tag: `v2.0.0`, annotated and unsigned, as Brad chose for this account, on main's `c1e7660`. GitHub release: [v2.0.0](https://github.com/memorex386/bradthome/releases/tag/v2.0.0).
- Main's `ci`, CodeQL and `next` passed on `c1e7660` before the tag. The first push, `360de53`, failed three test-environment checks, fixed forward in `c1e7660`.
- Run: [release 42279004266](https://github.com/memorex386/bradthome/actions/runs/42279004266), with `words-may-change=home`. The build ran in the pinned Playwright container and printed the résumé PDFs.
