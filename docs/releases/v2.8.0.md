# v2.8.0: the hero's role tiles, and evals that run what a change touches

bradthome.com moved from v2.7.0 to v2.8.0 on 2026-11-13 (UTC). The release puts two changes on live:

- **Slice 5.10, the hero's tiles and buttons ([spec 036](../../specs/036-hero-tiles/spec.md), [D223](../decisions/0223-the-role-tiles-are-the-switch.md)–[D227](../decisions/0227-the-phone-header-keeps-the-profiles-and-the-resume.md)):**
  - "What are you hiring for?" sits over three role tiles, which are the role switch. Each links its role page, which marks its tile and opens its detail.
  - Mobile and full-stack show live years, counted from May 2015 and Sep 2016: 11+ and 10+ today. The one module counts them again from the visitor's clock.
  - The buttons have icons, and the address has a copy button. GitHub and LinkedIn get chips with their preview cards, and Brad's avatar is on GitHub's.
  - On a phone, the header keeps GitHub, LinkedIn and the résumé beside the menu.
  - The chat's corpus gains the two years claims.
- **[Spec 037](../../specs/037-evals-changed-cases/spec.md), evals that run the cases a change touches ([D228](../decisions/0228-evals-run-the-cases-a-change-touches.md)):**
  - A push to an `evals/` branch asks only the new and edited cases. A full run happens when Brad asks, and `pnpm chat-api:deploy` needs one that passed with the code's prompt and model.
  - A failing case is asked once more. `/evals` shows both tries, and says what changed in the code since its run.

Brad asked in this session for the quickest and cheapest path to production, and approved the release in the `production` environment. The runbook is [docs/release.md](../release.md).
