# Rehearsal: release v2.2, roll back to v2.1

The rehearsal for spec 024 (slice 4.5, S9.3), run on 2026-11-09 after the flag's removal reached main at `f3983e0`, before v2.2 reached the live channel. It ran on preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, as Brad's own login, as the [v2.1.0 rehearsal](v2.1.0-rehearsal.md) did.

## Setup

- The candidate was `f3983e0`'s build, made in the pinned Playwright container by `pnpm test:visual`, with the résumé PDFs printed and `pnpm csp --check` passing. It was deployed with the repo's `firebase.json` to channel `v22-rc` as version `2c9f72604686b1f0`.
- Releases went to channel `rehearsal-v22`, created for the rehearsal, expiring a day later.
- v2.1.0, which bradthome.com serves, is version `ccb99f2bedeed4c5` (`pnpm release:status`).

## The pre-release check

Against bradthome.com, with the words allowed to change, as the release runs with `words-may-change=true`:

```text
$ pnpm release:check --candidate https://bradthome--v22-rc-nrvxbdwp.web.app --words-may-change
– check  Hosting sets its own HSTS on bradthome--v22-rc-nrvxbdwp.web.app, so the check reads firebase.json at f3983e0's: max-age=63072000; includeSubDomains
✓ check  https://bradthome--v22-rc-nrvxbdwp.web.app serves every URL, redirect, security header and word that https://bradthome.com does (31 URLs, 2 pages' words)
```

Prep lives in the chat's window, which loads on open, so neither compared page's words change. The privacy note gains prep's line, and `/evals` the latest run with prep's suites.
