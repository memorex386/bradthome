# Rehearsal: release v2.6, roll back to v2.5

The rehearsal for v2.6.0, which releases slice 5.8, "Ask about Brad" flying into the hero and back (spec 032). It ran on 2026-11-11 from main's `7bd1846`, before v2.6 reached the live channel. It ran on preview channels of the `bradthome` site only, with the scripts the release and rollback workflows run, as Brad's own login, as the [v2.5.0 rehearsal](v2.5.0-rehearsal.md) did.

## Setup

- The candidate was `7bd1846`'s build, made in the pinned Playwright container by `pnpm test:visual`, with the résumé PDFs printed and `pnpm csp --check` passing.
- It went first to channel `v26-rc`, as version `5f457e96550baf0f`. The pre-release check there read `/` and `/404` as 404s, though curl got 200. Hosting's CDN had cached its "Site Not Found" page, with `x-cache: HIT`, for the check's requests, from before the new channel was serving. The same build on a fresh channel, `v26-cand`, as version `84da3b8eb2ef8e34`, read correctly once it had been live for 30 seconds.
- Releases went to channel `rehearsal-v26`, created for the rehearsal, expiring a day later.
- v2.5.0, which bradthome.com served, is version `7b4ad229d17d38c2` (`pnpm release:status`).

## The pre-release check

Against bradthome.com, with no words allowed to change, since slice 5.8 changes none:

```text
$ pnpm release:check --candidate https://bradthome--v26-cand-8a7vte91.web.app
– check  Hosting sets its own HSTS on bradthome--v26-cand-8a7vte91.web.app, so the check reads firebase.json at 7bd1846's: max-age=63072000; includeSubDomains
✓ check  https://bradthome--v26-cand-8a7vte91.web.app serves every URL, redirect, security header and word that https://bradthome.com does (31 URLs, 2 pages' words)
```

## The run

```text
started 2026-11-11T20:13:17Z
created channel `rehearsal-v26`, at https://bradthome--rehearsal-v26-zuhcba18.web.app
$ node scripts/release/release.ts --version 84da3b8eb2ef8e34 --channel rehearsal-v26 --staged-channel v26-cand
✓ release  version 84da3b8eb2ef8e34 is served on rehearsal-v26 at https://bradthome--rehearsal-v26-zuhcba18.web.app: 39 files, after 3 s
$ node scripts/release/rollback.ts --channel rehearsal-v26 --version 7b4ad229d17d38c2
✓ rollback  version 7b4ad229d17d38c2 is served on rehearsal-v26 at https://bradthome--rehearsal-v26-zuhcba18.web.app: 39 files, rollback served after 5 s
rollback command took 6 s end to end
finished 2026-11-11T20:13:32Z
```

Each ✓ line means every file of the version answered at its address with its hash as the ETag.
