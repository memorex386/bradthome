# v2.6.0: "Ask about Brad" flies into the hero and back

bradthome.com moved from v2.5.0 to v2.6.0 on 2026-11-11 (UTC). The release puts slice 5.8 on live:

- [spec 032](../../specs/032-ask-flies-in/spec.md): on a phone the hero's button is the same pill as the corner's. Once its place is fully 100 px into the screen, the corner's pill flies there over 320 ms, aimed each frame at where the place is, and hands over to the hero's button; as the place leaves, it flies back. With reduced motion the two swap at once ([D215](../decisions/0215-ask-about-brad-flies-into-the-hero.md)).

Brad asked for the release in the session ("Release v2.6.0"), and approved it in the `production` environment. The rehearsal before it is in [v2.6.0-rehearsal.md](v2.6.0-rehearsal.md), and the runbook is [docs/release.md](../release.md).

## The release

- Tag: `v2.6.0`, annotated and unsigned like v2.5.0, on main's `7bd1846`. GitHub release: [v2.6.0](https://github.com/memorex386/bradthome/releases/tag/v2.6.0).
- Main's `ci`, `next` and "Push on main" passed on `7bd1846` before the tag.
- Run: [release 43094532251](https://github.com/memorex386/bradthome/actions/runs/43094532251), with no words allowed to change. The stage job put version `55eb8420929a08ec` on the `release` channel, and its pre-release check against v2.5.0 on bradthome.com printed:


- Brad approved the release job in the `production` environment. It printed:

  ```text
  ✓ release  version 55eb8420929a08ec is served on live at https://bradthome.com: 39 files, after 6 s
  ```

- `pnpm release:status` then read `live (https://bradthome.com) serves version 55eb8420929a08ec, released 2026-11-11T20:16:28.424Z: v2.6.0 (7bd1846)`. A rollback would put back v2.5.0's `7b4ad229d17d38c2`.

The chat API, its prompt and its model didn't change, so v2.6 needed no `pnpm chat-api:deploy` and no eval run.
