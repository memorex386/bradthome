# MIT for code, all rights reserved for content

## Context and problem statement

**The question:** Which licenses?

People can learn from the code but can't reuse Brad's writing or images. Follow-up F4 proposes switching to two plain license files, the common pattern.

## Considered options

The options are listed in the builder's ranked order.

1. MIT for code, all rights reserved for content, declared with REUSE (recommended, chosen)
2. The same licenses as two root files and a README note
3. MIT for everything
4. CC BY-NC-ND for content

## Decision outcome

Chosen option: "MIT for code, all rights reserved for content, declared with REUSE".

Licenses: MIT for the code, all rights reserved for the content, declared with REUSE.
