# Analytics with Umami Cloud

## Context and problem statement

**The question:** Analytics: which tool, if any?

Gives the charter's visitor measures without tracking that identifies visitors.

## Considered options

The options are listed in the builder's ranked order.

1. Umami Cloud, free (recommended, chosen)
2. GoatCounter
3. Plausible
4. No analytics

## Decision outcome

Chosen option: "Umami Cloud, free".

Analytics: Umami Cloud, free and cookieless, with custom events.
