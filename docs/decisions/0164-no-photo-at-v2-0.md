# No photo at v2.0

## Context and problem statement

The relaunch could include a photo of Brad, and the plan had slice 3.11 wait on one. Should v2.0 have a photo?

## Considered options

The options are listed in the builder's ranked order.

1. No photo for v2.0; one can come later as a content change (recommended)
2. Brad supplies a photo now

## Decision outcome

Chosen option 1. v2.0 ships with no photo. A photo Brad supplies can come later as its own content change. The agent never takes an image from LinkedIn or elsewhere.

### Consequences

- Good, because the release doesn't wait on a design pass and new baselines.
- Bad, because the page has no face on it for now.

### Confirmation

The plan's 3.11 row no longer waits on a photo.
