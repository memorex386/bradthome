# The first screen serves the phone skim

## Context and problem statement

**The question:** When visitors want different things, who wins?

Three visitor types come for different things. Recruiters give a first pass about seven seconds (Ladders eye-tracking).

## Considered options

The options are listed in the builder's ranked order.

1. The first screen for the skim, the rest for the interview (recommended, chosen)
2. Interviewers first, throughout
3. Recruiters first, throughout
4. Engineers first

## Decision outcome

Chosen option: "The first screen for the skim, the rest for the interview".

When visitors want different things, the first screen serves a recruiter skimming on a phone (under ten seconds: name, role, Hopper, proof, contact). Everything below it serves the interviewer. Engineers get clear paths to the essay and the repo.
