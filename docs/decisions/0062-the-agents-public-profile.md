# The agent's public profile

## Context and problem statement

**The question:** What does the agent's public profile say?

Interviewers who open a pull request may click the agent's name. GitHub's terms make Brad responsible for a machine account's actions, and the bio says so plainly.

## Considered options

The options are listed in the builder's ranked order.

1. A name, and a bio that says what it is (recommended, chosen)
2. A name only
3. Leave the profile empty

## Decision outcome

Chosen option: "A name, and a bio that says what it is".

The agent's public profile has the name "Brad Thome's agent" and the bio "Machine account for the AI coding agents that open pull requests in @memorex386's repos. Brad reviews and merges every one."
