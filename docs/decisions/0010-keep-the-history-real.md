# Keep the history real

## Context and problem statement

Nothing was ever committed, so a fresh start isn't a rewrite. Commit dates are public, and one staged step would cast doubt on the rest.

## Considered options

This decision was made in chat, before decisions moved to pages ([D28](0028-every-decision-goes-on-a-decision-page.md)), so its options weren't kept.

## Decision outcome

The history is real. Foundation commits come first, then today's site is rebuilt slice by slice with real dates. No backdating and no staged steps. The README calls v0 a one-day prototype.
