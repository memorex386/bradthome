# Spec 007: A demo

## User stories and acceptance scenarios

- **S1.1** Given a demo, when it runs, then it works.
- **S1.2** Given a second demo, when it runs, then it works too.

## Functional requirements

- **FR-001** The demo MUST run.
- **FR-002** The demo MUST stop.

## Success criteria

- **SC-001** The demo runs in under a second.
