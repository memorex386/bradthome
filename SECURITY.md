# Security policy

## Reporting a vulnerability

Report security problems privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Please don't open a public issue.

Include what you found, how to reproduce it, and what it affects. You'll get a reply as soon as possible.

## Scope

In scope:

- The code in this repository and the site it builds, bradthome.com.
- Secrets or private details exposed anywhere in this repository or its history.

Out of scope:

- Denial-of-service attacks, spam and social engineering.
- Problems in third-party services the site uses, such as GitHub or its hosting provider. Report those to the service.

## Supported versions

Only the current site, built from the `main` branch, gets fixes.
