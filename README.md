# bradthome.com

The source for [bradthome.com](https://bradthome.com), the personal site of Brad Thome, a senior mobile and full-stack engineer.

## Status

The site at bradthome.com today is v0, a one-day prototype. This repository rebuilds it from scratch, slice by slice, and the rebuild replaces v0 when it's ready. Until then, this repository holds the groundwork rather than the site.

## How it's built

Brad builds this site with AI coding agents. Every change starts from a spec or an issue that Brad approves. The agent's own GitHub account, [bradthome-agent](https://github.com/bradthome-agent), opens each pull request. A second agent reviews it with fresh context, and Brad merges it. The working agreement and the decisions behind the project come next.
